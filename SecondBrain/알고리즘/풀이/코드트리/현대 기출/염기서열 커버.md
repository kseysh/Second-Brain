## 정답 풀이

```java
import java.util.Scanner;

public class Main {
    // 두 문자열을 합치는 함수입니다.
    // 만약 합치는 것이 불가능하다면 빈 문자열이 반환됩니다.
    private static String add(String p, String q) {
        if (p.isEmpty() || q.isEmpty()) return "";
        StringBuilder ret = new StringBuilder();
        for (int i = 0; i < p.length(); i++) {
            if (p.charAt(i) == '.' && q.charAt(i) == '.') ret.append('.');
            else if (p.charAt(i) == '.') ret.append(q.charAt(i));
            else if (q.charAt(i) == '.') ret.append(p.charAt(i));
            else if (p.charAt(i) == q.charAt(i)) ret.append(p.charAt(i));
            else return "";
        }
        return ret.toString();
    }
    
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int N, M, C[];
        String P[];
        N = sc.nextInt();
        M = sc.nextInt();
        C = new int[1 << 15];
        P = new String[1 << 15];

        for (int i = 0; i < N; i++) P[1 << i] = sc.next(); // 배열 입력

        // 모든 가능한 조합에 대해 문자열을 합칩니다.
        for (int i = 3; i < (1 << N); i++) {
            // 'i & (-i)'는 i에서 가장 낮은 비트(가장 오른쪽에 있는 1)를 구합니다.
            // 예를 들어, i가 6(110)이면, x는 2(010)가 됩니다.
            int x = i & (-i);

            // x가 i와 같지 않다면, i는 여러 비트가 설정된 상태를 나타냅니다.
            // 이 경우, i에서 x를 뺀 부분과 x 부분의 문자열을 합칩니다.
            // 예를 들어, i가 6(110)이면, i - x는 4(100)이 되고,
            // P[4]와 P[2]를 합치는 것과 같습니다.
            if (x != i) P[i] = add(P[i - x], P[x]);
        }

        // 각 조합에 대해 최소 비용을 계산합니다.
        for (int i = 1; i < (1 << N); i++) {
            if (!P[i].isEmpty()) C[i] = 1;
            else {
                C[i] = 100;

                // i의 모든 부분집합을 j를 이용해 순회합니다.
                for (int j = (i - 1) & i; j > 0; j = (j - 1) & i) {
                    if (!P[i - j].isEmpty()) {
                        if (C[i] > C[j] + 1) C[i] = C[j] + 1;
                    }
                }
            }
        }

        System.out.println(C[(1 << N) - 1]);
    }
}

```

3부터 값을 올라가면서 값을 찾아나가므로 비트 하나를 빼면 그 두 bit는 무조건 이미 값이 할당되어 있는 비트이므로 이렇게 1 << N번을 돌면 모든 bit의 염기서열을 구할 수 있음

## 문제 해설

### **Intuition**

여러 문자열을 정 규칙에 따라 합칠 수 있는 최소 횟수를 찾는 문제를 해결합니다. 문자열은 특정 조건 하에만 합칠 수 있으며, 이를 통해 최종적으로 하나의 문자열을 만들어야 합니다. 이 문제는 각 문자열 조합의 가능성을 검사하고, 가능한 조합을 찾아 최소 횟수를 계산하는 방식으로 접근합니다. 이 과정은 문자열의 모든 가능한 조합을 비트마스킹을 통해 효율적으로 해결됩니다.

### **Algorithm**

먼저, 각 문자열 조합의 가능성을 검사합니다. 문자열이 합쳐질 수 있는지 여부는 각 문자의 위치에 따라 결정되며, 불가능한 경우 빈 문자열을 반환합니다. 그 후, 모든 가능한 문자열 조합에 대해 계산을 진행합니다. 이때, 각 조합은 비트마스킹을 사용하여 표현되며, 각 조합에 대한 최소 합치기 횟수를 계산합니다. 가능한 조합이면 현재 횟수를 1로 설정하고, 그렇지 않으면 다양한 부분집합을 고려하여 최소 횟수를 업데이트합니다. 이 과정은 모든 조합에 대해 반복되며, 최종적으로 모든 문자열이 합쳐진 상태에 대한 최소 횟수를 출력합니다.

이 알고리즘의 시간 복잡도는 문자열 조합의 수와 각 조합을 검사하는 데 필요한 시간에 의존합니다. 문자열의 수가 N일 때, 가능한 조합의 수는 2_N_이며, 각 조합을 검사하는 데 약 _O_(_N_2) 시간이 소요될 수 있습니다. 따라서 전체 시간 복잡도는 _O_(_N_2×2_N_)으로 볼 수 있습니다.

### **Complexity**

- Time Complexity: O(_N_2×2_N_)
- Space Complexity: O(2_N_×_L_)
