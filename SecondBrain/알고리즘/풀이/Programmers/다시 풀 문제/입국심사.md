## 정답 코드
```java
class Solution {
    
    static final long MAX_N = 1_000_000_000L;
    static final long MAX_TIME = 1_000_000_000L;
    static final int EXCEED = 1;
    static final int RIGHT = 0;
    static final int LACK = -1;
    
    public long solution(long n, int[] times) {
        return dfs(n, times, 1L, MAX_N * MAX_TIME);
    }
    
    public long dfs(long n, int[] times, long left, long right){
        if(left == right) return right;
        
        long mid = (left + right) / 2L;
        long auditPeopleCount = 0;
        
        for(int time : times){
            auditPeopleCount += mid / (long) time;
        }
        
        if(auditPeopleCount < n){
            return dfs(n, times, mid + 1, right);
        }else if (auditPeopleCount > n){
            // return dfs(n, times, left, mid - 1);
            return dfs(n, times, left, mid);
        }else{
            // return dfs(n, times, left - 1, mid);
            return dfs(n, times, left, mid);
        }
    }
}
```

거의 다 풀었는데 조건을 주석 친 곳처럼 작성해서 틀림
심사한 사람 수가 목표치보다 크다고 해서, 현재 시간을 정답 후보에서 완전히 배제해버리면 안됨.
