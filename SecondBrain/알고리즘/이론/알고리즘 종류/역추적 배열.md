최소 비용을 갱신할 때, 어떤 부분 집합 j를 선택해서 최적값이 되었는지 그 위치를 별도 배열에 기록해두는 방식
```java
int[] parent = new int[1 << N]; // 최적의 이전 상태(j)를 저장할 배열

// ... (생략) ...

for (int i = 1; i < (1 << N); i++) {
    if (!P[i].isEmpty()) {
        C[i] = 1;
    } else {
        C[i] = 100;
        for (int j = (i - 1) & i; j > 0; j = (j - 1) & i) {
            if (!P[i - j].isEmpty()) {
                if (C[i] > C[j] + 1) {
                    C[i] = C[j] + 1;
                    parent[i] = j; // ★ 핵심: 최적값을 만들어준 이전 상태(j)를 저장!
                }
            }
        }
    }
}
```

DP가 끝난 후, 목적지 상태에서 parent를 타고 거꾸로 따라 올라가면 어떤 노드들로 분할되어 들어왔는지 복원할 수 있다.
