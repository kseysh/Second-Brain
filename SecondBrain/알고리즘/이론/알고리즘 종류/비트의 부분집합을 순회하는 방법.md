```java
// i의 모든 부분집합을 j를 이용해 순회합니다.
for (int j = (i - 1) & i; j > 0; j = (j - 1) & i) {
}
```

성립하는 이유

1. `j - 1`은 무조건 `j`보다 엄격하게 작다 (j - 1 < j)
2. `& i` 연산을 해도 더 커질 수는 없다.

즉,

$$  
\text{다음 } j = (j - 1) \ \& \ i \le (j - 1)  
$$

$$  
\text{다음 } j \ = \ (j - 1) \ \& \ i \ \le \ (j - 1) \ < \ \text{현재 } j  
$$

⇒ **"다음 j는 무슨 짓을 해도 현재 j보다 엄격하게(Strictly) 작다!"**
