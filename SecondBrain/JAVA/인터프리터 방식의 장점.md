인터프리터는 매 명령어마다 배열 범위 초과, null 역참조, 권한 위반 등을 즉시 검사할 수 있어 샌드박스 구현에 적합하다

⇒ 컴파일 언어는 소스 코드를 기계어로 바꾼 뒤 CPU가 이를 직접 실행하게 만들기 때문에 실행 중에 배열 범위를 넘어가거나 잘못된 메모리 주소를 건드리면, OS 차원에서 프로그램이 강제 종료되거나 보안 취약점이 터질 수 있음

하지만, 인터프리터는 코드가 CPU로 직접 가기 전에 중간에서 한 줄씩 받아 읽고 처리하는 심판 역할을 한다.

코드가 실행되기 직전에 인터프리터라는 거대한 관리자 프로그램이 먼저 개입하기 때문에, 위험한 행동을 하는지 실행 순간마다 체크할 수 있는 공간이 자연스럽게 확보됩니다.
