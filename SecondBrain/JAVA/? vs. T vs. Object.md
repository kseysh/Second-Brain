GenericBox<?> vs. GenericBox

둘의 차이는 Raw type은 여러 타입이 들어갈 수 있는 반면, 와일드 카드는 단 하나의 타입만 들어갈 수 있다. (실제 실행될 때는 단 하나의 명확한 특정 타입으로 고정되어 있지만, 지금 당장 컴파일러만 그게 무슨 타입인지 모른다.)


- **`<T> void process(List<T> a, List<T> b)`**
    - **의미:** "`a`와 `b`는 **서로 같은 타입**이어야 해!" (두 인자 사이에 '타입 종속성/관계'가 존재함)
- **`void process(List<?> a, List<?> b)`**
    - **의미:** "`a`와 `b`의 타입은 **서로 달라도 아무 상관없어!**" (두 인자 사이에 관계가 없음)

|**구분**|**List<Object>**|**List<?>**|
|---|---|---|
|**의미**|**`Object` 타입** 요소들의 리스트|**특정 한 타입(Unknown)** 요소들의 리스트|
|**데이터 추가 (`add`)**|`String`, `Integer` 등 **아무거나 추가 가능**|**`null`을 제외한 모든 데이터 추가 불가**|
|**다형성 (대입)**|`List<String>`을 **대입할 수 없음**|`List<String>`, `List<Integer>` 등 **모두 대입 가능**|
|**타입 안전성**|런타임에 `ClassCastException` 위험 존재|컴파일 타임에 **타입 오염을 완벽히 방지**|
